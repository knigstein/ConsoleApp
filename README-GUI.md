# JavaFX GUI — локальная проверка

Клиент с картой корпуса (Ломоносова, 9), таблицей коллекции и всеми командами лабораторной работы.

## Быстрый старт (без сервера)

```bash
./run-gui-client.sh mock
```

или:

```bash
./gradlew runGuiClient -PappArgs="--mock"
```

1. Экран **входа / регистрации** — любой логин и пароль (данные в памяти).
2. Краткое **приветствие** по времени суток (`java.time.LocalTime`).
3. **Карта** — вкладки этажей 1–5, планы из `Corpus/834200.jpg` … `834204.jpg`; маркеры внутри аудиторий.
3. **Таблица** — полная коллекция, фильтры, сортировка, **10 строк на страницу**.
4. **Боковая панель** — все команды (`show`, `info`, `add`, `clear`, фильтры, `execute_script` и т.д.).

## С реальным сервером

```bash
./run-gui-client.sh real localhost 5555
```

Сервер должен быть запущен (UDP, порт по умолчанию 5555). На Helios развёртывание и PostgreSQL — отдельный этап; логика команд на сервере не меняется.

## Планы этажей

Исходники: `Corpus/834200.jpg` … `834204.jpg`.

При `./lab5 build` каталог `Corpus/` копируется в `deploy/helios/Corpus` (нужен для карты этажей в GUI).

## Структура GUI

| Компонент | Назначение |
|-----------|------------|
| `GuiClientApp` | Точка входа: подключение → Login → Main |
| `LoginView` | Авторизация / регистрация |
| `MainView` | Шапка, карта/таблица, статус |
| `FloorMapView` | План этажа + маркеры на Canvas |
| `TablePage` | Таблица с пагинацией |
| `CommandsPanel` | Кнопки всех команд |
| `GuiController` | Сессия, сеть, mock, выполнение команд |

## Локали

`ru`, `be-BY`, `hu`, `en-IE` — переключатель на экране входа и в шапке.

## Требования

- JDK 17+
- JavaFX подтягивается Gradle (OpenJFX 21)
- Для mock-сборки нужен доступ к Maven при первом `./gradlew`
